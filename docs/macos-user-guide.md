# 我的文献库 · Mac 首版使用说明

## 安装与启动

日常使用固定安装在 `/Applications/我的文献库.app`，从应用程序文件夹或 Dock 启动。没有系统应用目录写入权限时，首次安装使用 `~/Applications/我的文献库.app`。请不要把 `release/` 中的版本目录作为日常启动位置。

0.1.8 起，本机开发更新使用 `rtk proxy npm run desktop:update`：构建新版和 DMG → 使用隔离临时库验收实际应用 → 正常退出旧版 → 安装到固定位置 → 启动新版并检查本地服务。开发交付时由 Codex 执行，不需要每次手动拖动安装包或先按 ⌘Q。构建或验收失败不会关闭正在使用的旧版。

已验证的现有包可用 `rtk proxy npm run desktop:install` 安装并启动；可指定源 `.app` 路径以及 `--target /完整路径/我的文献库.app`。0.1.10 安装包位于 `release/我的文献库-0.1.10-arm64.dmg`，可用于手动安装或分发到其他电脑。

本版适用于 Apple Silicon Mac、macOS 13 及以上。应用包含运行时和钥匙串助手，不需要额外安装 Node、npm 或 Xcode。产物已作本地 ad hoc 签章，尚未完成 Developer ID 签名和 Apple 公证；它是本机测试版。

首次启动沿用网页版的现有数据库、PDF 目录及钥匙串账户。请先退出正在写入同一论文库的网页本地服务，再启动桌面版；Codex MCP 通过桌面版服务读取数据。

更新沿用现有论文库、PDF、笔记和钥匙串密钥，它们保存在应用包之外。更新请求仍经过既有笔记保存及草稿检查：有未保存编辑或保存失败时会取消退出、保留旧版，请在应用中保存后重试。安装先验证暂存副本，保留旧包直到新版通过启动检查；替换或启动失败时尝试恢复旧版，不能正常退出的应用不会被强制终止或删除。当前是本机开发交付更新，不会定时从互联网下载版本。

0.1.1 恢复 macOS 系统标题栏，可从顶部标题栏拖动窗口，从边缘调整大小。主工具栏根据侧边栏之外的可用宽度换行；最窄窗口仍保留搜索、筛选、排序、AI 设置和添加论文。

## 收集与整理

主窗口保留完整论文卡片：中英文题目、作者与机构、发表信息、分类、AI 总结、个人笔记和资源状态。可切换题目列表、小／标准／大字号，并按分类、收藏、近期想看及关键词检索。

桌面版点击卡片题目或题目列表条目，有本地 PDF 或 PDF 来源链接时直接进入阅读器；没有可读 PDF 时打开论文编辑区，可补充链接或选择本地文件。编辑资料仍可从卡片「更多操作 → 编辑论文」进入。阅读后返回保留搜索条件、展示模式、滚动位置及题目焦点。

「添加论文」接受题目、DOI、arXiv 或链接。可交给 AI 联网整理，再人工检查并确认保存；也可手动填写。

0.1.9 起，拖入 PDF 或使用「文件 → 导入 PDF」会打开「导入 PDF 资料」，支持博客、教程、讲义及论文。默认以文件名填写标题，标题可以是中文或其他语言；作者、日期、来源、分类和链接均可留空，填写标题即可确认入库，不需要 DOI、会议／期刊或 AI 识别。保存后可与论文一起搜索、分类、阅读和做笔记。在编辑现有记录时导入，则附加到该记录；多份 PDF 按顺序确认入库。

本地资料确认保存时按标准化标题与已有标识查重，未保存的草稿不显示“未发现重复”。需要按论文联网整理时，可点击「按论文识别」返回线索输入，再点击「交给 AI 整理」；AI 只使用输入线索，不读取 PDF 内容。PDF 内容哈希仍用于归档与阅读版本记录，尚不用于跨记录文件查重。

0.1.10 起，首次导入时即可填写「来源 / 网站」「机构」和「笔记 / 备注」，点击确认后与资料一起保存，无需入库后再打开编辑。笔记支持中文与多行文本，会直接显示在资料卡片和 PDF 阅读器的个人笔记中。切换「按论文识别」后返回手动填写会保留已有来源、机构和备注；AI 整理不会生成或覆盖个人笔记。多文件导入时每份资料有独立草稿，下一份不会带入上一份备注；保存被查重拦截时已填内容仍保留。

添加窗口顶部的「添加论文提示词 → 查看与编辑」可查看完整默认提示词。你可以修改检索策略、摘要要求和整理规则，点击「保存提示词」后，后续添加论文及文献雷达候选核对都会使用这份提示词；关闭应用、更新和重新启动后仍保留。可用「取消修改」还原未保存的草稿，或「恢复默认」重新使用内置模板。请保留默认 JSON 输出字段，使 AI 结果能正常填入资料表。

查看、编辑、保存和恢复提示词不调用 AI，也不要求先配置 API Key。未保存修改时，需要先保存或取消修改，再运行 AI 或关闭添加窗口。此设置与雷达生成候选论文的提示词分别保存。

0.1.6 修复联网过程说明和残缺 JSON 片段干扰最终资料解析的问题，默认提示词中的 JSON 示例使用实际合法枚举值。使用默认提示词时更新后自动生效，自定义提示词继续保留。若模型最终没有给出完整 JSON 或缺少确认的原文题目，会提示重试／切换模型，保留线索且不添加论文；不会凭缺失资料猜测，也不自动发起额外 AI 请求。

0.1.7 为 DeepSeek 官方接口增加公开来源预读：提供项目网页、arXiv 链接／编号或 DOI 时，应用先读取公开页面及明确关联的论文来源，再交给模型生成结构化资料。不会执行页面脚本或读取 PDF 全文；无法读取来源时会在调用 AI 前停止。格式失败时可展开「查看 AI 最终答复」查看有长度限制的纯文本，原输入仍保留。

## AI 服务与文献雷达

在「AI 设置」填写服务名称、Base URL、API Key 和模型 ID，验证后使用。API Key 保存在 macOS 钥匙串；不要在聊天里粘贴密钥。应用内 AI 录入和文献雷达仍使用你的 API 服务。

DeepSeek 官方 Responses 接口不支持内置联网搜索。0.1.7 可用它整理明确的公开链接；纯题目／描述检索及文献雷达全网发现，需要使用支持 Responses 联网工具的服务与模型。不支持的场景会明确提示，不会发送无效的付费请求。其他兼容网关按其实际联网能力使用原有流程。

文献雷达沿用研究范围、联网检索、去重及人工审核流程。候选论文确认后才进入文献库。验证模型和运行 AI／雷达会调用配置的 API；纯手动整理、阅读与 Codex 本地检索不会调用它。

## 阅读与笔记

点击卡片的 PDF 进入内置阅读器。在线 PDF 先归档到本机，再读取；也可导入本地文件。页面连续纵向排列，使用触控板或鼠标上下滚动即可跨页阅读；页码会跟随当前位置，仍可输入页码直接跳转。

点击「显示目录」展开左侧导航，可切换 PDF 内置章节目录和页面缩略图。章节支持展开子目录并跳到对应页；没有内置目录时自动显示缩略图。导航栏和右侧笔记栏均可独立收起。

触控板双指捏合可围绕指针位置放大或缩小 PDF；放大后可上下、左右滑动查看页面。工具栏保留缩放按钮和适应宽度。支持文字选择和全文查找，搜索结果可直接定位到对应页。扫描版 PDF 暂无 OCR，全文查找需要文件已有文字层。

笔记自动保存，返回前会完成保存；失败时显示重试入口并保留本机草稿。再次打开会恢复页码、页面内位置、缩放与笔记面板。替换为不同内容的 PDF 后，阅读位置按新文件重置。

PDF 来源临时返回 500／502／503／504 时会有限重试。需要登录的来源应在浏览器中登录并下载：打开失败页可选择「重试下载」「在浏览器打开 PDF 来源」「打开论文页面」，或「导入本地 PDF」直接附加到当前论文。导入前会保存笔记，取消不修改记录，失败保留草稿，成功后仍在当前阅读器打开，不新建重复论文。

就绪的有效本地 PDF 优先读取；远程刷新失败会保留已有文件。本地导入的文件不会因为论文还保存着远程来源链接而被自动替换。请自行核对导入文件的论文和版本；预印本与正式发表稿可能不同。

| 快捷键 | 功能 |
| --- | --- |
| ⌘N | 添加论文 |
| ⌘O | 导入 PDF |
| ⌘F | 在文献库搜索；阅读时查找 PDF |
| ⌘K | 搜索入口 |
| ⌘, | 设置 |
| ⌘W | 隐藏当前窗口，保留草稿及本地服务 |
| ⌘Q | 保存检查通过后退出应用 |

关闭窗口后仍可从 Dock 恢复，Codex 也可继续检索。明确退出应用后，本地服务停止；有未保存编辑或保存失败时会取消退出。

## 在 Codex 中讨论论文

本机已注册 MCP 服务 `personal_literature_library`。重启 Codex 连接后，保持文献应用运行，即可说：

> 先查我的论文库，结合摘要和我的笔记讨论这个研究方向。请区分论文元数据、AI 总结和个人笔记。

> 根据讨论整理待收集论文，给出完整原文题目、DOI／arXiv、来源链接和是否已入库。

MCP 提供概览、库内搜索和读取论文记录。它只读，不自动入库；将待收集论文的题目或标识符粘贴到应用「添加论文」即可审核收集。默认包含个人笔记，可在连接环境变量中关闭。

当前检索范围为元数据、AI 总结和可选笔记；PDF 原文尚未建立知识库全文索引。被返回的相关记录会进入当前 Codex 对话上下文。详细设置及边界见 [Codex 论文库连接](codex-library-connection.md)。

## 数据与备份

- 数据库：`~/Library/Application Support/个人文献库/library.sqlite3`
- PDF：`~/Library/Application Support/个人文献库/pdfs`
- 数据库快照：`~/Library/Mobile Documents/com~apple~CloudDocs/个人文献库备份`

「数据与 Codex 连接」设置可在 Finder 中定位这些位置。数据库快照不包含 PDF 文件，完整迁移时需同时保存 PDF 目录；API Key 由系统钥匙串单独管理。

## 开发与验收

`npm run desktop:dev` 启动桌面开发版；`npm run desktop:package` 仅生成安装包；`npm run desktop:update` 完成打包、验收、安装和重启。`npm run desktop:smoke` 使用独立临时数据目录，检查真实桌面进程、阅读器和保存恢复，不触碰用户论文库。测试版不包含你的私有初始数据或 API Key。

验证记录见 [实施进度](implementation-progress.md)。
