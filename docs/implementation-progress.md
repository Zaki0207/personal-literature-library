## 重要集成契约

桌面 API 由独立 utility process 单点写入，端口随机；受限 preload 传输 renderer 请求。运行信息写入 `~/Library/Application Support/个人文献库/runtime.json`（0600），仅供本机 MCP/主进程使用，包含 `apiUrl`、每次运行的 `token`、`pid`、`version`。API 支持 Bearer token（桌面模式），renderer 不接触 token。MCP 不直接打开会迁移／初始化的 repository，也不触发应用内付费 AI。
